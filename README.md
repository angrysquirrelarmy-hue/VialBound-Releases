# VialBound builds

Builds of VialBound for the self-updating launcher. The game's source isn't here.

## SteamOS (Legion Go S, Steam Deck) and Linux

1. In Desktop Mode, download **VialBound-SteamOS-Launcher.tar.gz** from the [latest release](../../releases/latest).
2. Extract it (right-click > Extract > Extract archive here), then right-click **install.sh** > Run In Konsole.
   It downloads the game and adds VialBound to your Steam library.
3. Back in Gaming Mode, VialBound is under Library > Non-Steam.

Every time you press PLAY the launcher checks here for a newer build and downloads only the files that
changed. With no internet it plays the installed version. Saves are never touched by updates.
